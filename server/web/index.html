Emparejar con el NAS

En la web de tu NAS, ve a Conexiones → Móviles → Añadir. Ponle un nombre (por ejemplo «Suitcase»), elige el volumen y la carpeta, y copia el código que empieza por datame-movil:. Pégalo aquí.

El código da permiso para leer y añadir ficheros en tus volúmenes, nunca para borrar. Si lo pierdes o ya no lo usas, bórralo en la web del NAS.
